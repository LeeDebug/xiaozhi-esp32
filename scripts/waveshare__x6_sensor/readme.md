# Environment X6 Sensor · 全 API 调试工具

微雪 **Environment X6 Sensor**（SKU 34169）的串口协议调试工具。基于 Python + Tkinter，
覆盖[官方文档](https://docs.waveshare.net/Environment_X6_Sensor/)里的**全部 8 条指令**，
每条指令一个测试卡片，实时展示发送帧 / 接收帧，并逐字段翻译成中文含义。

环境使用 **[uv](https://docs.astral.sh/uv/)** 管理，端口**在启动后从下拉框选择**，不再写死端口号。

---

## 目录结构

| 文件 | 说明 |
| --- | --- |
| `main.py` | GUI 主程序（端口选择 + 8 个 API 测试卡片 + 实时日志 + 数值面板） |
| `x6_protocol.py` | 协议模块：0-add8 校验、8 条指令的组帧 / 解帧 / 中文解析，可直接命令行自测 |
| `pyproject.toml` | uv 项目配置与依赖声明 |
| `uv.lock` | 锁定的依赖版本 |
| `readme.md` | 本文档 |

## 一、初始化环境

### 1. 安装 uv（只需一次）

Windows（PowerShell，任选一种）：

```powershell
winget install astral-sh.uv
```

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

macOS / Linux：

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

装完确认：

```bash
uv --version
```

### 2. 初始化项目环境

在本目录（`main.py` 所在目录）执行：

```bash
uv sync
```

这一步会：

- 自动下载/选用合适的 CPython（当前锁定 3.12）
- 在本目录创建 `.venv` 虚拟环境
- 按 `uv.lock` 安装 `pyserial` 等依赖

> 想固定 Python 版本，可先执行 `uv python pin 3.12`；想看现有解释器列表用 `uv python list`。

## 二、打开（激活）虚拟环境

**方式 A：不激活，直接用 `uv run`（推荐）**

`uv run` 会自动识别并使用本目录的 `.venv`，每条命令都带上 `uv run` 前缀即可，不需要手动激活。

**方式 B：手动激活 `.venv`，在交互式的 shell 里操作**

Git Bash / macOS / Linux：

```bash
source .venv/Scripts/activate      # Windows(Git Bash)
source .venv/bin/activate          # macOS / Linux
```

CMD：

```bat
.venv\Scripts\activate.bat
```

PowerShell：

```powershell
.venv\Scripts\Activate.ps1
```

激活后命令行前面会出现 `(.venv)` 前缀。验证一下：

```bash
python -c "import serial, tkinter; print('OK', serial.__version__)"
```

退出虚拟环境：`deactivate`

## 三、启动

```bash
uv run main.py
```

（若已按方式 B 激活了 `.venv`，直接 `python main.py` 也可以。）

### 其它命令行用法

```bash
# 只列出当前可用串口（方便确认插在哪一个 COM 上），列完即退出
uv run main.py --list

# 启动并把某个串口作为默认值预填（仍可在界面里改）
uv run main.py --port COM12

# 离线解析一帧十六进制数据，不开串口也能验证协议
uv run main.py --hex "70 42 30 00 00 3D 35 64 F0 3D 53 D2 5B 3D 08 19 55 0A C8 27 0F E0"

# 跑协议模块自带的回归自测（用官方文档的 7 个样例帧）
uv run python x6_protocol.py
```

## 四、如何使用

### 4.1 硬件连接

| X6 引脚 | 接到 USB-TO-TTL |
| --- | --- |
| VCC | 5V |
| GND | GND |
| RXD | TXD |
| TXD | RXD |

> 传感器 IO 电平为 **3.3V**，接 5V 电平必须做电平转换，否则会损坏传感器。
> 串口参数固定 **9600 / 8 / N / 1**（界面里波特率默认 9600，一般不用改）。

### 4.2 选择端口

1. 插上传感器，点界面右上角的 **「刷新端口」**，下拉框会列出所有串口，
   格式如 `COM12 — USB-SERIAL CH340 (COM12)`。
2. 选中实际那个端口，点 **「打开串口」**；状态变成绿色的「已连接」即可开始测试。
3. 支持热插拔：拔插后点「刷新端口」重新选择。
4. 如果下拉框里没有（某些驱动不会上报描述），可以**手动输入**端口号，例如 `COM12`。

### 4.3 界面分区

```
┌──────────────────────────────────────────────────────────────┐
│ 串口栏：端口下拉框 / 波特率 / 打开串口 / 刷新端口 / 状态      │  ← 启动后选端口
├────────────────────────┬─────────────────────────────────────┤
│ API 测试卡片区          │ 实时通信日志                        │
│  0x70 查询当前浓度      │   ▶ 发送  发送 · 查询当前浓度        │
│  0x72 读取传感器参数    │     HEX   70 90                     │
│  0x74 读取 LED 状态     │     ├─ 指令头 0x70 —— 查询当前浓度   │
│  0x56 设置运行灯状态    │     └─ 校验和 0x90 —— 0-add8 ...    │
│  0x54 进入休眠模式      │   ◀ 接收  接收 · 查询当前浓度        │
│  0x55 退出休眠模式      │     HEX   70 42 30 ... E0           │
│  0x71 获取 SN           │     ├─ IAQ  42 30 00 00  44.00 ...  │
│  0x73 获取版本号        │     └─ 校验和 0xE0  校验通过         │
│  自定义原始帧           │   ▣ 解析  IAQ 44.0（良好）｜...      │
├────────────────────────┴─────────────────────────────────────┤
│ 实时数值：每格上行「中文 + 单位」、下行「英文缩写」           │
│   空气质量等级格可点击 → 弹出每级含义与建议对照表             │
└──────────────────────────────────────────────────────────────┘
```

日志区的三种标记：

- `▶ 发送`（蓝）：本次实际发出的帧 + 逐段中文说明
- `◀ 接收`（绿）/ `⚠ 异常`（红）：收到的帧 + 逐字段中文解析 + 校验结果
- `▣ 解析`（蓝）：一句话中文总结

### 4.4 八个 API 卡片

| 卡片 | 指令 | 操作 | 返回 |
| --- | --- | --- | --- |
| 查询当前浓度 | `0x70` | 点「查询一次」 | 22 字节：IAQ / TVOC / HCHO / CO / 温度 / 湿度 |
| 读取传感器参数 | `0x72` | 选通道后「读取」，或「读取全部 4 个通道」 | 7 字节：气体类型、量程、单位 |
| 读取 LED 状态 | `0x74` | 点「读取 LED 状态」 | 3 字节：`0x00` 关闭，`0x01` 闪烁 |
| 设置运行灯状态 | `0x56` | 选 关闭/开启 后「设置」 | 5 字节：返回 `OK` 表示成功 |
| 进入休眠模式 | `0x54` | 点「发送休眠指令」（发 ASCII `sleep`） | 5 字节：返回 `OK` |
| 退出休眠模式 | `0x55` | 点「发送唤醒指令」（发 ASCII `awake`） | 5 字节：返回 `OK` |
| 获取序列号 SN | `0x71` | 点「读取 SN」 | 8 字节：6 字节 SN |
| 获取版本号 | `0x73` | 点「读取版本号」 | 21 字节：19 字节 ASCII 版本串 |

> 底部数值面板每格**上行是「中文 + 单位」、下行是英文缩写**（如「甲醛 (ppm)」/ `HCHO`）；
> 右侧「**空气质量等级**」格可以**点击**，会弹出 IAQ 各等级的范围、含义与建议对照表，
> 并自动高亮当前读数所在的等级，再次点击或按 Esc 关闭。

### 4.5 连续采集与数据存档

- 在 **0x70** 卡片里点「**开始连续采集**」，按设定的间隔（默认 1 秒）自动轮询浓度。
- 「**同时记录（data/ 目录按天存档）**」**默认勾选**，无需选保存位置：
  - 每次 0x70 的读数自动写入 `data/x6_log_YYYY-MM-DD.xlsx`（如 `x6_log_2026-09-30.xlsx`）；
  - 同一天重复采集会**追加**到同一个文件，跨天自动切换到新文件；
  - 文件是标准 Excel 表：第 1 行是合并居中的标题「翊燊科技 环境监测系统 日志记录 <日期>」
    （日期与文件名一致），第 2 行是加粗居中的表头，采用「中文 + 单位 + 英文」形式
    （如「甲醛 (ppm) HCHO」「总挥发物 (ppm) TVOC」），列宽已按内容调好，
    第 3 行起为数据并居中对齐，冻结前两行方便滚动浏览；
    打开旧格式文件时会自动把表头迁移成新格式，已有数据不受影响；
  - 数据先在内存里攒着，每 20 行或每 30 秒自动落盘一次；若文件正被 Excel 打开会提示，
    关闭 Excel 后自动补写。
- 「**保存日志**」把当前日志区内容导出成 txt；「清空」清空日志区。

### 4.6 自定义原始帧

最下面一张卡片可以手填十六进制（如 `70`），自动补 0-add8 校验和后发送；
如果自己已经带上了校验字节，勾选「已含校验和」。用于调试文档之外的指令。

### 4.7 注意事项

- 传感器**休眠后不再响应 0x70**，需要先发 `0x55` 唤醒。
- 同一时刻只有一个请求在串口上进行，多条请求会排队，不会串帧。
- 若 2 秒内无应答，日志会给出排查提示（TX/RX 是否反接、供电、波特率、是否在休眠）。

## 五、协议速查表

### 通信参数

- UART，**9600 bps**，数据位 8，停止位 1，无校验，无流控
- 字节序：**大端**（高字节在前）
- 帧结构：指令头 + Data + 校验和
- 校验和 **0-add8**：所有字节相加 → 取低 8 位 → 按位取反 → 加 1
  （等价于 `(-sum(data)) & 0xFF`；补上校验字节后整体和 ≡ 0 mod 256）

### 指令与发送帧

| 指令 | 名称 | 发送帧（HEX） | 应答长度 |
| --- | --- | --- | --- |
| `0x70` | 查询当前浓度 | `70 90` | 22 |
| `0x72` | 读参数 · IAQ | `72 00 8E` | 7 |
| `0x72` | 读参数 · TVOC | `72 01 8D` | 7 |
| `0x72` | 读参数 · HCHO | `72 02 8C` | 7 |
| `0x72` | 读参数 · CO | `72 03 8B` | 7 |
| `0x74` | 读取 LED 状态 | `74 8C` | 3 |
| `0x56` | 关闭运行灯 | `56 00 AA` | 5 |
| `0x56` | 开启运行灯 | `56 01 A9` | 5 |
| `0x54` | 进入休眠 | `54 73 6C 65 65 70 93`（`sleep`） | 5 |
| `0x55` | 退出休眠 | `55 61 77 61 6B 65 A2`（`awake`） | 5 |
| `0x71` | 获取 SN | `71 8F` | 8 |
| `0x73` | 获取版本号 | `73 8D` | 21 |

> 校验和由程序实时计算。注意：官方文档 0x72 示例里写的 `0x8D` 是按 0x73 抄错的，
> `72 00` 的正确校验和是 `0x8E`（文档应答示例的 `0x87` 同理应为 `0x88`）。程序按算法计算，不受影响。

### 应答字段含义

**0x70 浓度帧（22 字节）**

| 字节 | 字段 | 含义 |
| --- | --- | --- |
| 0 | 指令头 | `0x70` |
| 1–4 | IAQ | IEEE754 浮点，室内空气质量指数 |
| 5–8 | TVOC | IEEE754 浮点，ppm |
| 9–12 | HCHO | IEEE754 浮点，ppm |
| 13–16 | CO | IEEE754 浮点，ppm |
| 17–18 | 温度 | uint16 ÷ 100，℃ |
| 19–20 | 湿度 | uint16 ÷ 100，%RH |
| 21 | 校验和 | 0-add8 |

**0x72 参数帧（7 字节）**：`头 | 气体编号 | 气体类型编号 | 量程(uint16) | 单位 | 校验和`
其余指令（0x54/0x55/0x56）统一为：`头 | 保留(0x00) | "OK"(4F 4B) | 校验和`

### 编码对照

| 气体编号（请求） | 名称 | 气体类型编号（应答） |
| --- | --- | --- |
| `0x00` | IAQ | `0x33` |
| `0x01` | TVOC | `0x18` |
| `0x02` | HCHO | `0x17` |
| `0x03` | CO | `0x19` |

| 单位编码 | 含义 |
| --- | --- |
| `0x00` | IAQ（空气质量指数，无量纲） |
| `0x02` | ppm（百万分比浓度） |

| IAQ 范围 | 等级 |
| --- | --- |
| 0–50 | 良好 |
| 51–100 | 中等 |
| 101–150 | 对敏感人群不健康 |
| 151–200 | 不健康 |
| 201–300 | 非常不健康 |
| 301–500 | 危险 |

## 六、常见问题

**Q：下拉框里没有我的串口？**
先点「刷新端口」；仍没有则检查 USB 线与 CH340/CP210x 驱动是否装好，
或在设备管理器里确认端口号后**手动输入**到下拉框。

**Q：打开串口失败 / 提示被占用？**
SSCOM、Arduino IDE、PlatformIO 串口监视器等会独占端口，先关闭它们再打开。

**Q：一直「超时无响应」？**
按日志里的提示排查：TX/RX 是否接反、供电是否为 5V、波特率是否 9600、
传感器是否处于休眠（先点「发送唤醒指令」）。

**Q：日志出现「校验失败」？**
多半是线路干扰或波特率不对，导致字节错位。可配合「自定义原始帧」抓原始字节排查。

**Q：缺 `tkinter`？**
`uv` 装的 CPython 一般自带 Tk；若报错，改用系统 Python 创建环境：
`uv venv --python <系统python路径>` 然后 `uv sync`。

**Q：我想改依赖 / 升级？**
改 `pyproject.toml` 后执行 `uv sync`；只更新锁文件用 `uv lock --upgrade`。
