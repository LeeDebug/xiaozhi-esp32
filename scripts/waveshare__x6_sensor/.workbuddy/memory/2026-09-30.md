# 2026-09-30

## 微雪 Environment X6 Sensor 调试工具改造

- 把原来的单文件串口解析脚本（`main.py`，只支持 0x70、端口写死在命令行）改造成 uv 管理的 GUI 调试工具。
- 新增/改动：
  - `pyproject.toml` + `uv.lock`：uv 环境，依赖 pyserial（GUI 用内置 tkinter，uv 的 CPython 3.12 自带 Tk 8.6，已验证）。
  - `x6_protocol.py`：协议模块。0-add8 校验 `(-sum)&0xFF`；8 条指令 0x70/0x72/0x74/0x56/0x54/0x55/0x71/0x73 的组帧、解帧、逐字段中文解析；`python x6_protocol.py` 可用官方 7 个样例帧做回归自测。
  - `main.py`：Tkinter GUI。端口从下拉框选（支持刷新/手输，不再写死）、8 个 API 测试卡片 + 自定义原始帧、实时收发日志（▶发送/◀接收/▣解析 + 中文逐字段注释）、数值面板与 IAQ 等级、连续采集与 CSV 导出。
  - `readme.md`、`.gitignore`（忽略 .venv）。
- 关键设计：串口独占在一条后台线程里串行处理请求队列，GUI 只通过 `queue.Queue` + `after()` 消费日志，避免串帧和线程安全问题。
- 文档坑：微雪文档 0x72 示例的校验和写错（`72 00` 应为 `0x8E`，文档写 `0x8D`；应答示例 `0x87` 应为 `0x88`），代码按算法实时计算，已写进 readme。
- 验证方式：用 `serial.Serial` 打桩的假串口喂应答，驱动 GUI 跑完 8 条 API + 连续采集 + 关闭，无异常（临时脚本跑完即删）。
