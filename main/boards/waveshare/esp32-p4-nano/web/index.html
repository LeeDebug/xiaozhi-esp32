01 / CONNECTION

串口连接

电脑模拟从机，接收单片机的 RTU 请求。

空闲达到此间隔才校验整帧。9600-8N1 默认 4 ms；USB 分片延迟大时可调高。连接期间锁定。

使用桌面 Chrome / Edge，通过 localhost 或 HTTPS 打开。

固件等待响应 1000 ms。关闭自动响应或增加延迟可模拟超时。

WIRING / 接线

连接业务串口

P4 UART1 · TX GPIO20 / RX GPIO21
9600 baud · 8 data · no parity · 1 stop

RS485：USB-RS485 的 A/B 连接板端收发器 A/B，按模块要求共地。使用自动方向切换适配器。

TTL：仅在板端为 3.3V UART 时交叉连接 TX ↔ RX，并共地。不要将 RS485 A/B 直接接 GPIO。

选择连接业务总线的适配器；开发板下载 / 日志口不等于 UART1。适配器应关闭本地回显。

03 / TRAFFIC INSPECTOR

通讯监视器

时间 / 方向原始报文 & 指令解析
等待请求。真实串口与离线报文会分别标记。

显示 CRC、从机地址、功能码、寄存器范围和读写值；最多保留 300 条。按接收空闲间隔划帧；噪声 / CRC 错误整帧丢弃，不扫描有效子帧，其他地址不响应。
